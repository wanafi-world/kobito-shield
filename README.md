# こびとの盾（kobito-shield）

防御しかできない小人が主人公の、横スクロールアクションの試作品です。
直接の攻撃はできません。盾とチェーンとジャンプだけで、虫たちを穴に落としたり、攻撃を跳ね返したりして進みます。

iPadのブラウザ（Safari）で遊べるように作っています。

## 遊び方

公開ページ: https://wanafi-world.github.io/kobito-shield/

iPadは横向きにして遊んでください。共有ボタンから「ホーム画面に追加」をすると、全画面に近い形で遊べます。

| 操作 | iPad | キーボード |
| --- | --- | --- |
| 移動 | 画面の左半分のどこかを触って、指をずらす（触った場所がスティックの中心になります） | ← → または A D |
| ジャンプ | ジャンプボタン | Z / スペース |
| 盾 | 盾ボタン（押している間構える） | X |
| チェーン | チェーンボタン（スティックを上や下に倒しながら押すと上下に伸びる） | C（↑ ↓ と一緒に押すと上下） |

### 盾
- 構えている間、前からの攻撃を防ぎます。
- 構えた直後の一瞬（0.18秒）は **パリィ** になります。針は速くなって跳ね返り、敵は大きく吹き飛びます。
- 構えたまま敵に近づくと押し返せます。穴に落とせば倒せます。

### チェーン
- 上下左右に伸ばせます。壁や天井にかかると、そこまで引っぱられてぶら下がります。
- 天井にぶら下がっている間はスティックを左右に倒すと横に進めます。下に倒すと降ります。
- 引っぱられた後は、空中で1回ジャンプできます。
- 敵に当たると少しノックバックします（ダメージはありません）。

### 敵
- **アリ**: 歩いているだけ。盾で押して穴に落とします。
- **ハチ**: 光ってから針を飛ばします。パリィで跳ね返して当てると倒せます。
- **カブトムシ**: こびとを見つけると突進します。壁にぶつけるかパリィするとひっくり返るので、押して穴に落とします。突進に巻き込まれた虫も倒れます。

## 手元で動かす

ビルドは不要です。フォルダで簡単なサーバーを立ててブラウザで開きます。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## ファイル構成

- `index.html`: ページ本体
- `src/main.js`: ゲームの設定（画面サイズなど）
- `src/GameScene.js`: こびと、敵、盾、チェーンの動き。動きの数値はファイル先頭の `P` にまとまっています
- `src/level.js`: ステージの地形、敵の配置、看板の文章
- `src/controls.js`: キーボードとタッチボタン
- `src/textures.js`: 仮の絵（図形を組み合わせて作っています）
- `vendor/phaser.min.js`: ゲームエンジン Phaser 3.80.1（MITライセンス）
